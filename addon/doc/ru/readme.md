# GoldWave

* Авторы: Joseph Lee, Day Garwood, участники сообщества NVDA.

Этот модуль приложения улучшает доступность и использование звукового редактора GoldWave.

## Горячие клавиши

Все команды поддерживают режим речи по требованию.

* Control+Shift+P: Объявляет текущую позицию дорожки.
* NVDA+Shift+R: Объявляет оставшееся время текущей редактируемой дорожки.
* Control+NVDA+1: Объявляет канал, который вы редактируете.
* Control+NVDA+2: Объявляет общую длину аудиофайла.
* Control+NVDA+3: Сводное объявление выделеной звуковой информации.
* Control+NVDA+4: Объявляет уровень.

Для получения более подробной информации о GoldWave и командах клавиатуры обратитесь к руководству пользователя GoldWave.

Примечание: Требуется GoldWave 6 или выше и Windows 10 или 11.

Список изменений, вносимых между каждыми выпусками дополнения, смотрите в документе [список изменений для выпусков дополнения][1].
